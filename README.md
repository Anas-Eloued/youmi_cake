## 🚀 Comment Lancer la Démo en 5 Secondes

### Option 1 (Le plus simple - Zéro terminal requis) :
- Double-cliquez directement sur **[`index.html`](index.html)** dans l'explorateur de fichiers.
- Il s'ouvre instantanément dans Google Chrome ou Microsoft Edge.

### Option 2 (Serveur local Node.js) :
Dans ce dossier, ouvrez un terminal et tapez :
```bash
npm start
```
Puis accédez à : **`http://localhost:3000`**
